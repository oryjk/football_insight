# 战术板云端草稿与显式发布验证

日期：2026-10-19。设计见 [spec](superpowers/specs/2026-10-19-lineup-draft-publish-design.md)。

## 结果

- 每用户每球队一份云端私密草稿，保存允许 0–11 人。公开版本继续使用原记录；只有发布入口要求满 11 人并更新公开快照。
- 发布与旧版保存入口通过同一 repository 原子事务同步私密草稿；存草稿只写私密表，公开分享码、点赞、创建时间不变。旧 GET/PUT 保持兼容。
- 前端四个操作均带线性图标；发布/更新发布沿用居中确认，草稿仅轻提示；分享只读取明确发布的快照，不隐式保存或发布。
- 本机稿按账号隔离；只有登录恢复明确触发的游客意图会移交游客稿，旧 autosave 标记只存私密草稿。保存期间的新编辑、切队/切账号后的迟到结果均受上下文保护。
