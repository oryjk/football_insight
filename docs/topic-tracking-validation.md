# 动态球队新闻与话题追踪验证

## 需求与实现

- 每次运行依据当前赛季排名动态选中超前三/后三、中甲前二；完整参赛数从双循环赛程轮数推得，拒绝缺尾、缺中间、重复排名与异常赛季。全量参赛球队字典用于对手标签，不扩大关注范围。
- 原文列表标题不限球队关键字；正文获取、真实发布时间和 72 小时窗口仍严格校验。多来源交错下载，防止 RSS 饥饿。链接去重取代全局发布时间水位，未来查询快照时钟也不会阻挡原文。
- 一文多球队标签；新文主体标签由编辑模型选择，程序验证原文与成文依据及关注范围。排名变化时重筛 pending，并将当前关注 ID 纳入正文缓存键、TTS 前校验缓存范围。
- 详情顶部标签可点击，文末显示当前话题和此前同球队时间线；支持切换、分页、重试、点击历史文章。游标绑定当前文章和球队。使用项目 token、跨端 uni API 和直接 Vue 组件导入。
- 显式历史补标签工具只改 JSONB 标签，旧正文/音频/日期/ID/热度保持原值；中乙希拉谷不归到中超蓉城。

## 实测

- Python：175 项全套测试通过（含显式隔离 PostgreSQL 的未来快照与标签补写保护），默认不配置隔离库时这两项跳过。
- Rust：399 项通过、56 项既有外部集成测试忽略；另显式执行 `daily_topics_postgres` 8 项通过。HTTP 覆盖标签、时间锚点、分页、串用游标、非法球队及缺失锚点；真实 SQL 验证跨批次去重及旧数据兼容。
- 前端：560 项测试、类型检查、依赖边界、H5 和微信离线构建、组件注册/API 产物检查通过；未分配新审核版本、未上传。
- 真实来源采集：本次动态名单为成都蓉城/大连英博/北京国安/辽宁铁人/武汉三镇/青岛海牛，以及广东广州豹/南通支云（仅记录本次快照，不是硬编码名单）。获得 13 篇完整原文，涵盖国安亚冠、海牛降级、广州豹冲超及蓉城评论；这次实测不调用 LLM/TTS、不写生产。
- 本地验证后端 18114 使用新编译进程启动，隔离 `football_topics_test` 数据库中复制公开历史新闻后补标签；未复制用户或交易数据。真实 HTTP 返回分页历史；Chromium 390×844 验证标签切换、时间线、正文位置及无运行错误。
- 严格 Clippy 与全仓六边形扫描仍有既有告警，涉及 admin/auth/ai/insight/payment/mini_review 等旧模块；本次 daily_topics 改动未新增命中。编译与功能测试通过。

## 发布状态与顺序

当前是本地分支实现与验证；生产 peiqian 后端、local233 原 checkout 的 cron 代码、小程序线上版本未更新。生产新闻/标签未改写。

发布顺序：合并业务改动 → 发布并重启后端（先验证旧接口及新 timeline）→ 只读预览并核对历史标签，显式补写 → 在 local233 更新采集代码（沿用原 cron）→ 从干净 main 在 Mac 按项目规范上传小程序。无需数据库迁移；模型/音频/凭据和数据缓存不提交 Git。
