# 洞察页统一容器与背景渐隐验证

日期：2026-10-19；基线 `a81cff1`。仅小程序改动。

## 结果

- 回流看板保持独立，球队选择、数据洞察/战术胶囊及对应内容由一个 FiPanel 承载，默认仍为数据洞察。
- 赛前倾向、球队概览和贡献分析保留原展示组件和数据流；内部 FiPanel 通过内容区继承的组件 token 去掉背景、圆角、边框、阴影与重复内边距。父页面用真实 view 负责布局与分隔，避免小程序 scoped 样式穿透问题。
- 我的战术改为浅底内嵌区，公开战术列表用分隔线，骨架屏与空态融入同一底板。未更改接口、会话、会员/审核条件、曝光、排序和点赞逻辑。
- 球场图保留，洞察页改用首页渐隐：透明 45%、半透明 78%、页面浅底色 100%，图高 600rpx。首页原参数收口为共享 token，视觉参数不变；洞察页底色衔接渐变终点。

使用 H5 和 Playwright，API 全部 mock，不写生产数据；球场图使用现有图片地址。

- 320px 游客、390px 登录用户、390px 权益暂停用户、430px 登录用户均通过。

- 登录用户可查看赛前倾向、球队概览和贡献；内层 FiPanel 的实际背景为透明、边框和内边距为零、阴影为 none。游客和权益暂停提示正常。
