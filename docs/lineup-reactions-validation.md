# 战术内容赞踩胶囊

日期：2026-10-19；基线 `15ac4d4`。

## 行为

- 洞察战术列表、球队战术列表和公开详情统一使用深灰圆角胶囊：左侧白色点赞图标与原始赞数，中间细分隔线，右侧点踩图标；只显示赞数。
- 赞、踩互斥，再点已选项取消；请求中两侧共同禁用。失败保留原状态，游客跳登录并保留返回页；换账号、换队、排序和卸载后的旧响应不能覆盖新状态。点赞榜继续按正向赞数排序。
- 小程序组件由父级真实 view 承担 flex 布局，类选择器避免组件 WXSS 警告，直接导入 Vue 组件确保微信注册。

## 后端与迁移

- 保留 `/like` 的 PUT/DELETE，新增 `/dislike` PUT/DELETE，均要求有效登录及可公开阵容；公开列表、详情和写响应新增 `disliked_by_me`。前端接受旧响应缺少该字段。
- repository 在单个事务里锁账号/作者/阵容，再替换互斥反应并返回服务端状态；领域/application/port 不依赖 SQLx 或 HTTP。
- `20261019160000_add_lineup_dislikes.sql` 仅新增点踩表、索引和两表互斥触发器，不改已有赞数。触发器保证旧后端插入点赞时也能替换该用户已有点踩，允许旧/新后端共存。
- **共享生产库迁移未执行，本地后端未重启，生产后端未部署/重启，小程序未上传。** 本地 18092 仍为原服务，点踩需先确认应用共享生产库迁移，再编译/重启本地后端；生产后端容器的发布另行安排。
