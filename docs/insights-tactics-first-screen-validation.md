# 洞察页战术首屏验证

日期：2026-10-19。基线 `8267d31`，仅小程序变化。

## 实现与架构

- 回流看板固定置顶 → 球队选择 → FiSegmented 胶囊切换数据洞察/战术，默认战术；我的云稿/发布摘要和球队公开战术同屏。
- 仅统计、归因、赛前参考归入数据 tab；回流入口不随 tab 切换。原会员/审核规则保留，公开战术不依赖这些私有请求。
- `useInsightsTeams` 独立拥有公开选队，统计和赛程只消费该选择；用户显式选择/本地偏好优先于慢主队响应。
- 共享 `useLineupCommunity`、`FiLineupCommunityCard` 和 `lineupPresentation` 同时服务洞察与独立战术列表/详情，无跨页导入或新边界豁免；局部展示组件仅 props/emits。
- 私有云稿、公开列表并行；切队/身份/不可见请求隔离，从编辑/详情返回刷新。切 tab 复用成功缓存，进行中的点赞可能落服务端时重新取公开状态。
- 独立复核发现并修正：保留既有身份的会话刷新错误不应改为游客；回流入口仅在页面可见且原权限/审核条件满足时计曝光，不依赖 tab；点赞期间选队/切 tab/刷新与排序重载的最终状态补刷。最终复核无剩余阻断项。
