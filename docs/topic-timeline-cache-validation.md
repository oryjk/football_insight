# 话题追踪缓存与切换验证

2026-10-14，前端修改；不涉及后端、数据库或定时任务。

## 行为

- 缓存仅属于当前详情页、当前话题。各球队独立保存已加载分页、下一页游标、成功空结果、错误与在途请求；切回已加载球队不请求首屏，直接恢复已有结果。
- 首次查看球队仍请求时间线。快速往返复用该球队在途请求；后台返回写入对应球队缓存，不覆盖当前选择。换话题或退出使旧请求失效。
- 分页失败保留此前结果和游标，重试请求同一页；错误首屏不当成成功缓存。
- 追踪区域按实际内容测量并保留当前文章已显示过的最大高度，避免页面底部收缩。较短或空列表底部会保留空白；新话题重新测量，不设全局固定高度或内部滚动条。
- 使用 `uni.createSelectorQuery().in(instance)` 测量原生组件，尺寸换算为 rpx；切换前使用组件 `$nextTick()` 等待微信 `setData` 回调完成，让保留高度先到达视图层。快速连点以最后选择为准。
