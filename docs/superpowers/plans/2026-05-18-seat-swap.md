# Current Match Seat Swap Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a Chengdu Rongcheng current-match seat swap feature with a Rust backend module, MinIO-backed cancellation evidence, and a sixth mini-program tab.

**Architecture:** Add a new `seat_swap` bounded context in the Rust Axum backend following the existing hexagonal module pattern. The module stores seat swap requests, desired regions, confirmations, and cancellation evidence in PostgreSQL, reuses ticket-watch current match/regions as the current-match gate, and exposes `/api/v1/seat-swap/*`. The mini-program gets a standalone `pages/seat-swap/index` tab that reads the current pool, lets logged-in users publish/update/confirm/cancel, and hides sensitive contacts unless the backend marks a candidate as contact-visible.

**Tech Stack:** Rust 2024, Axum 0.8, SQLx/PostgreSQL, reqwest for MinIO S3-compatible upload, uni-app Vue 3, TypeScript, Bun.
