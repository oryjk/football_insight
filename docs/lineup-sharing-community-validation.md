# 战术板分享、点赞与球队榜单验证

日期：2026-10-19。设计与接口规则见 [spec](superpowers/specs/2026-10-19-lineup-sharing-community-design.md)。

## 实现与公开规则

保存满 11 人自动公开；不足 11 人不公开，再次保存满员沿用分享码与创建时间。球队榜单按创建时间倒序或点赞数倒序，同赞数再按创建时间/ID 稳定排序。游客可读列表与详情，活跃账号才能点赞/取消及获取分享码图片。作者停用隐藏阵容，停用点赞者不计数。HTTP 输出仅有公开昵称和头像，不包含内部账号标识。

分享卡片直达只读详情；海报包含队徽、作者、球员头像/号码、前队员标记及小程序码。二维码失败阻断导出并提供重试。静默登录、切队、切排序与旧请求响应隔离，点赞请求防重。
