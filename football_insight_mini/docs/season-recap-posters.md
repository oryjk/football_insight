# 我的赛季海报

2026-10-21：深色「热血夜场」与浅色「赛季珍藏」共用真实观赛数据。

## 展示与生成

- 在赛季总结页选择样式，生成后可保存、分享。更换样式或修改勾选/主场距离会使旧海报失效；生成期间不能切换样式。
- 背景仅包含「我的赛季」毛笔标题、球场、第12人球迷与 TIFO。真实成都队徽、赛季、里程、称号、进度、城市和客场队徽由 Canvas 绘制。
- 750 × 1536 固定绘制坐标；预览按宽度等比展示，不依赖屏幕分辨率排列卡片。三项统计各占一行，标题和数值共享基线；不显示算法或进度条下的小字。
- 客场、主场、足迹进度分别按对应参赛场次 / 整季有效场次计算，颜色随轨道向右加深。总里程直接使用后端 summary，不重新估算。
- 客场城市按比赛日期去重，至多显示6城，超过时注明总城市数；同城多个对手保留各自队徽，头像缺失时仍显示城市。
- 页脚保留真实小程序码、品牌和里程估算说明；分享链接不携带账号或所选比赛。

## 内部称号规则

权重：主场1，客场2。分母来自后端 `season_totals` 的整季有效赛程，包含未开赛、进行中和延期比赛；取消、失效赛程排除。可勾选列表仍只返回已结束的一线队比赛。

优先顺序：

1. 未参加比赛：尚未启程。
2. 整季全部主客场都已结束且全部参加：全勤死忠。
3. 主场至少10场且客场0场：主场守护者。
4. 其余按加权参赛率：低于25%为蓉城同行者、25%至不足50%为主场死忠、50%至不足75%为蓉城铁杆、75%及以上为铁血死忠。

按原始数值比较，不四舍五入跨级。旧后端没有 `season_totals` 时不将已结束场次当成整季、不授予全勤、不绘制未知进度；仍可生成里程与足迹。

## 素材

源文件与生成说明：`assets/season-recap/README.md`。背景通过已加入下载白名单的现有 MinIO 域名加载；新对象为独立v2路径，不覆盖旧背景。两张背景不放入小程序主包。

## 验证

- `bun test src/pages/season-recap`：称号阈值、全勤、主场专属称号、零场次/缺元数据、主题切换及迟到结果隔离、图片失败降级。
- `bun run type-check`、`bun run check:boundaries`。
- `MINI_REVIEW_SKIP=1 bun run build:mp-weixin`：离线构建和组件注册，不申请版本、不上传。
- `bun run build:h5`；用实际 Canvas 绘制函数检查深浅主题、零场次、六城市与长数值。
- 后端 `cargo test --lib season_recap`；显式一次性测试库运行 `season_recap::adapters::persistence::tests::isolated_migration_and_repository -- --ignored`，验证完整赛程计数、延期/取消/失效与赛季隔离。不能指向生产库。

后端只增加响应元数据，不需要数据库迁移；生产发布时应先更新后端再上传小程序。
